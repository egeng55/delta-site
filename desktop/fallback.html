Start backend command

The app runs this fixed command with `.env` loaded in the main process. Secrets are not exposed to this page.

cd /Users/egeng/delta-backend
set -a; source .env; set +a
.venv/bin/python -m uvicorn api_server:app --host 127.0.0.1 --port 8000

Start site command

The app runs this fixed command from the site repo. It does not run arbitrary shell input.

cd /Users/egeng/delta-site
npm run dev -- --hostname 127.0.0.1 --port 3000

Safety posture

  • No microphone capture, browser mic, wake word, or always-on listener is started.
  • No backend TTS, browser TTS playback, desktop notification, or delivery side effect is run.
  • No memory writes, feedback writes, migrations, schema changes, or Supabase mutations are performed.
  • Stop controls affect only backend/site child processes launched by this desktop app.
